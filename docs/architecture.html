Architecture overview

Factory Inventory Management System

A demo dashboard for factory operations. A Vue 3 single-page app calls a FastAPI service. The service serves and filters JSON loaded into memory at startup. There is no database, no auth backend, and no writes persist.

System architecture

Three tiers, all running locally. Every request is a read against in-memory Python lists.

Data flow: changing a filter

The path a request takes when a user picks a warehouse, category, status, or time period.

  1. User changes a filter in FilterBarThe four selections live in module-level refs in useFilters.js, so every view shares one filter state.
  2. The view re-fetchesIt calls getCurrentFilters(), which maps the time period to month (for example 2025-03 or Q1-2025).
  3. api.js builds the requestIt drops any value set to all and sends the rest as query params, for example GET /api/orders?warehouse=Tokyo&month=Q1-2025.
  4. FastAPI filters in memoryapply_filters matches warehouse, category, and status (case-insensitive). filter_by_month does a substring match on order_date, expanding quarters to three months.
  5. Pydantic validates the responseList endpoints declare a response_model. The summary, spending, and reports endpoints return plain dicts.
  6. Vue derives what to displayRaw responses go into refs such as allOrders and inventoryItems. Totals, chart series, and top-N lists are computed properties. Currency is converted client-side (USD to JPY at a fixed 150).

Things to know

Gaps and quirks found while reading the code.

Unfinished features. The client calls task and purchase-order endpoints that the server does not define. Dashboard.vue also renders a PurchaseOrderModal component that does not exist in the repo.
An unrouted view: views/Backlog.vue exists but has no route in main.js. Backlog data appears on the Dashboard instead.
Inconsistent API access: Reports.vue hardcodes http://localhost:8001 and uses axios directly instead of going through api.js.
Data is fixed to 2025: the quarter map and the report grouping hardcode 2025 months. The demand, backlog, and spending endpoints ignore the global filters.
Mock user: useAuth.js returns a hardcoded profile. Locale choice is saved in localStorage.
